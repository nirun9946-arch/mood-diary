# ไดอารี่ความรู้สึก (Mood Diary)

เว็บบันทึกเหตุการณ์ ความรู้สึก และคะแนนความสุขรายวัน พร้อมอินโฟกราฟิกแสดงสภาพจิตใจ

## สิ่งที่มีในหน้าเว็บ

- **การ์ดสรุป** — คะแนนความสุขเฉลี่ยพร้อมทิศทางแนวโน้ม, จำนวนบันทึก, วันที่มีความสุขที่สุด, สถานะความรู้สึกที่พบบ่อยที่สุด
- **เกจสภาพจิตใจ** — คำนวณจาก 5 บันทึกล่าสุด พร้อมคำอธิบายสถานะ
- **กราฟความสุขรายวัน** — แยกเส้นตามคน ชี้ที่จุดเพื่อดูรายละเอียดของวันนั้น
- **โดนัทสัดส่วนสถานะความรู้สึก** และ **แท่งระดับความรู้สึก Lv.1–7 / Lv.X**
- **ปฏิทินความสุข** — ระบายสีตามคะแนนของแต่ละวัน เลือกดูย้อนหลังรายเดือนได้
- **สรุปอัตโนมัติ** — อ่านข้อมูลแล้วเขียนข้อสังเกตให้เป็นภาษาคน

## การใช้งาน

เปิด `index.html` ได้เลย ไม่ต้องติดตั้งอะไร ไม่ต้องต่อเน็ต ไม่มีไฟล์แนบ

- กรอกฟอร์มด้านล่างหน้าเพื่อเพิ่มบันทึก
- แท็บด้านบนใช้กรองดูรายคน
- ทุกรายการในไทม์ไลน์กด ✏️ เพื่อแก้ หรือ 🗑️ เพื่อลบ
- ปุ่ม 🌙/☀️ สลับธีมสว่าง–มืด (จำค่าไว้ให้)

## เรื่องข้อมูล

ข้อมูลเก็บใน **localStorage ของเบราว์เซอร์แต่ละเครื่อง** ไม่มีเซิร์ฟเวอร์ ไม่มีการส่งข้อมูลออกไปที่ไหน

- เขียนจากมือถือจะไม่เห็นในคอม — ย้ายข้อมูลด้วยปุ่ม **ส่งออก** แล้ว **นำเข้า** ที่อีกเครื่อง
- ล้างข้อมูลเบราว์เซอร์เมื่อไหร่ บันทึกจะหาย ควรกดส่งออกเก็บไฟล์ไว้เป็นระยะ

ข้อมูลตั้งต้นในไฟล์ (ตัวแปร `SEED`) คัดลอกมาจาก Google Sheet ต้นทาง เป็นข้อมูลนิ่ง ไม่ได้ซิงก์กับชีต

## ระดับความรู้สึก

| Level | สถานะ | ความหมาย |
|---|---|---|
| Lv.1 | Acquaintance | แค่คนรู้จัก ทักทายตามมารยาท |
| Lv.2 | Curious / Friendly | เริ่มรู้สึกว่าน่าสนใจ คุยด้วยแล้วสบายใจ เป็นมิตร |
| Lv.3 | Attracted / Crush | เริ่มมีใจ คิดถึงบ่อย ใจเต้นเวลาคุย |
| Lv.4 | Confused / Overthinking | สับสน ไม่แน่ใจในความสัมพันธ์ คิดมาก |
| Lv.5 | Caring / Attached | ผูกพัน ห่วงใย อยากดูแล |
| Lv.6 | In Love | รักและมั่นใจในความรู้สึกที่มี |
| Lv.7 | Hurt / Healing | เจ็บ เสียใจ กำลังเยียวยาตัวเอง |
| Lv.X | ยังไม่นิยาม | ยังไม่รู้ว่าตัวเองรู้สึกยังไง |

แก้รายการนี้ได้ที่ตัวแปร `MOODS` ในไฟล์ `index.html`
