ไดอารี่ความรู้สึก

ไดอารี่นี้เป็นของส่วนตัว ต้องล็อกอินก่อนจึงจะเห็นบันทึกที่แชร์กัน ล็อกอินครั้งเดียวเครื่องจะจำไว้ให้

ตั้งค่า

ค่าทั้งหมดเก็บไว้ในเบราว์เซอร์เครื่องนี้เท่านั้น ไม่ได้บันทึกลงโค้ดของเว็บ และไม่มีใครอื่นเห็น

ซิงก์ข้อมูลข้ามเครื่อง

ตอนนี้บันทึกเก็บอยู่ในเบราว์เซอร์ของแต่ละเครื่องแยกกัน ฝนเขียนในเครื่องฝน เป็ดจึงไม่เห็น ถ้าอยากให้เป็นไทม์ไลน์เดียวกัน ต้องมีที่เก็บข้อมูลกลาง — สมัคร Supabase ฟรี แล้ววาง 2 ค่านี้ลงไป ระบบจะซิงก์ให้อัตโนมัติทุกครั้งที่บันทึก

คีย์ anon ของ Supabase ออกแบบมาให้เปิดเผยได้ แต่ต้องตั้ง Row Level Security ในโปรเจกต์ให้เรียบร้อย ไม่งั้นใครที่รู้ค่านี้จะอ่านและเขียนข้อมูลได้ กด "วิธีตั้งค่า" เพื่อดูขั้นตอนและ SQL ที่ต้องรัน

AI ช่วยวิเคราะห์

ใส่คีย์ของคุณเองเพื่อให้โมเดลภาษาอ่านบันทึกทั้งหมดแล้ววิเคราะห์ความรู้สึกของทั้งสองคน เมื่อตั้งค่าแล้วปุ่ม "วิเคราะห์ด้วย AI" จะขึ้นในการ์ดวิเคราะห์ และผลล่าสุดจะถูกเก็บไว้ให้ดูได้ตลอด

อย่าส่งคีย์ให้ใครทางแชตหรือข้อความ ถ้าเคยส่งไปแล้วให้ถือว่าคีย์นั้นรั่ว ควรลบทิ้งแล้วสร้างใหม่
คีย์ที่ใส่ตรงนี้เก็บอยู่ใน localStorage ของเบราว์เซอร์เครื่องนี้เท่านั้น ไม่ถูกบันทึกลงโค้ดของเว็บ และไม่มีใครที่เปิดลิงก์นี้เห็น แต่ถ้าใช้เครื่องร่วมกับคนอื่นก็ไม่ควรใส่ทิ้งไว้
